# ShotCraft：短视频局部重创作系统

面向短视频后期中的穿帮物体清理和指定元素替换。用户提供视频、目标提示/掩码、编辑指令和保留约束，系统输出编辑候选、质量报告及可追溯的任务记录。

VideoPainter 作为可替换的底层生成组件；本仓库负责需求约束、时序掩码控制、分镜调度、候选评测和应用流程。保留上游来源和许可。

## 项目目标

1. 让局部编辑服从指定时间范围、目标区域和保留区域。
2. 减少目标移动、遮挡和分镜切换导致的掩码失配与编辑闪烁。
3. 提供基线、消融和失败案例，验证自研模块是否改善实际编辑结果。
4. 保存模型版本、输入哈希、参数、种子、失败原因及运行资源。

## 实现状态

项目初始化阶段。当前已实现请求协议、跨镜头窗口调度、待训练的时序掩码残差模块及 VideoPainter 直接适配层，25 项核心/接口测试通过，推理依赖实际导入通过；尚未完成 VideoPainter 真实生成、模块训练、质量提升实验或应用界面。以 reports 中的真实记录为准。

代码使用 Python / PyTorch，Windows / CUDA 开发，生成后端通过独立环境隔离。完整模型权重下载前先核查磁盘与显存。初始推理环境规格以官方实现为基线，兼容性尚待实测。
