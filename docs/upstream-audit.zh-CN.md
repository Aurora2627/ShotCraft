# VideoPainter 接入审查

上游：https://github.com/TencentARC/VideoPainter
固定提交：bbab6cd5cd5cb89f0e2444305c32fd74a010ae0a。

1. 官方 infer/inpaint.py 的输入数据读取耦合 VPBench/VPData 目录和 CSV 列，不能直接当任意用户视频 API。
2. 模块导入时构造 OpenAI 客户端；本地生成不应因此要求用户 API 密钥或将视频发送到外部服务。我们的后端将直接加载底层 pipeline，提示词改写单独设计为可选组件。
3. 官方脚本将多个组件直接放进 CUDA，不能据此保证 8 GiB 设备可运行；需单独验证 CPU offload、显存、内存与速度。
4. 官方可视化函数拼接原片、掩码片与结果。系统评测必须保存原始生成帧，不能将对比展示视频当作原始候选。
5. 帧采样与输出 fps 在示例脚本中有固定假设；应用层必须自行维护帧时间和音频同步。
6. 首帧参考需要显式定义，区分真实编辑参考、原片首帧和人工/图像模型生成的参考。移除目标时不能把含目标的原片当作“正确编辑首帧”。
7. 下游代码不通过改写上游作者与版权信息获得原创性。上游是固定第三方生成后端，我们的算法、评测和系统代码分别维护。

此文档为源码审查结论；尚不构成生成成功或效果验证。
